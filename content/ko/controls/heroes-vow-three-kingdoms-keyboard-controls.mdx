### "좋은 조작"이 실제로 의미하는 것

조작 체계는 그것에 대해 생각하지 않게 될 때 좋습니다. 이를 가능하게 하는 세 가지 요소가 있습니다:

- **접근성:** 모든 전투 동작이 쉬고 있는 손 위치에서 키 하나 이내에 있습니다.
- **충돌 없음:** 중요한 동작이 메뉴나 카메라 기능과 같은 키를 공유하지 않습니다.
- **일관성:** 비슷한 동작은 결투, 캠페인, 메뉴 전반에서 비슷한 키를 사용합니다.

커뮤니티 보고에 따르면, 첫 대규모 전투 전에 키를 재할당한 플레이어가 기본 설정에 "익숙해진" 뒤 나중에 문제를 고치는 플레이어보다 더 빨리 적응합니다.

### 전투 조작 vs. 메뉴 조작

흔한 실수는 전투와 메뉴 키 설정을 하나의 시스템으로 취급하는 것입니다. 그렇지 않습니다. 전투 키에는 속도와 낮은 오류 위험이 필요하고, 메뉴 키는 전투를 방해하지 않도록 치우쳐 있어야 합니다. 전투 동작은 왼손 클러스터에, 메뉴는 키보드 바깥쪽 가장자리에 두면 대부분의 실수 입력을 막을 수 있습니다.

| 계층 | 우선순위 | 이상적인 위치 |
|---|---|---|
| 전투 | 속도, 충돌 없음 | 홈 행 + 마우스 버튼 |
| 카메라 | 부드럽고 연속적 | 마우스 움직임과 휠 |
| 메뉴 | 의도적, 치우친 위치 | 바깥쪽 키(M, I, Esc) |
| 소셜 / 시스템 | 거의 사용 안 함 | 키보드 구석 |

## 조작을 확인하고 재할당하는 단계별 방법

과정은 짧지만 순서가 중요합니다. 테스트 없이 키를 하나씩 재할당하면 전투 중간에야 알아차리게 되는 충돌이 생깁니다.

| 단계 | 할 일 | 도움이 되는 이유 |
|---|---|---|
| 1 | 메인 메뉴 또는 일시정지 화면에서 **설정 → 조작** 열기 | 해당 빌드가 사용하는 배치를 보여줌 |
| 2 | 현재 키 설정을 스크린샷 찍거나 적어 두기 | 변경이 마음에 들지 않을 때 되돌릴 수 있음 |
| 3 | 전투 동작부터 재할당(공격, 방어, 회피, 록온) | 실패 비용이 가장 큼 |
| 4 | 낮은 위험의 전투나 훈련 모드에서 각 변경 테스트 | 콤보 중간에 키에 닿을 수 있는지 확인 |
| 5 | 카메라와 메뉴 키는 마지막에 재할당 | 우선순위와 위험이 낮음 |
| 6 | 게임을 재시작하고 한 번의 전투를 다시 플레이 | 설정이 제대로 저장됐는지 확인 |
| 7 | 옵션이 있다면 설정 파일 백업 저장 | 패치 후 복구 속도 향상 |

빌드가 여러 프로필을 지원한다면 키보드 플레이용과 컨트롤러용을 하나씩 만들어 다시 작업할 일이 없게 하세요.

### 따라야 할 키 재할당 규칙

- 두 개의 자주 쓰는 동작을 같은 키에 할당하지 마세요.
- 키보드의 안티 고스팅이 지원하지 않는 키는 피하세요 — 저렴한 멤브레인 보드는 동시에 세 번 누르면 입력이 씹힙니다.
- 회피와 방어는 서로 다른 손가락에 두어 손을 떼지 않고 반응할 수 있게 하세요.
- 키 설정이 영리해 보이지만 어색하다면, 그것은 어색한 것입니다. 바꾸세요.

## 흔한 조작 문제 해결

대부분의 조작 관련 불만은 게임 자체보다 소프트웨어 충돌에서 비롯됩니다. 다음은 플레이어들이 가장 자주 효과를 봤다고 보고한 해결책입니다.

| 증상 | 가능한 원인 | 해결 |
|---|---|---|
| 전투 중 키가 작동하지 않음 | 게임 창이 포커스를 잃음 | 게임 창을 클릭하거나 전체 화면으로 실행 |
| 입력이 두 번 등록됨 | 두 번째 장치가 여전히 연결됨 | 컨트롤러를 분리하거나 추가 입력 장치 비활성화 |
| 업데이트 후 키 설정이 초기화됨 | 설정 파일 덮어쓰기 | 설정을 다시 적용하고 백업 복사본 유지 |
| 마우스 카메라가 굼뜨게 느껴짐 | 낮은 감도 또는 무거운 마우스 | 감도를 점진적으로 높이고 마우스 DPI 확인 |
| 캐릭터가 계속 움직임 | 키가 눌린 상태이거나 토글 모드 활성화 | 토글 설정을 확인하고 키보드 테스트 |
| 키보드 대신 컨트롤러가 감지됨 | 자동 입력 전환 | 조작 설정 메뉴에서 키보드로 강제 설정 |

문제가 지속되면 플랫폼 런처를 통해 게임 파일을 검증하고, 키보드에서 키 입력을 가로채는 매크로 소프트웨어가 실행 중이 아닌지 확인하세요.

**키보드 대신 컨트롤러로 플레이할 수 있나요?**
예. 대부분의 버전이 게임패드 입력을 지원하며, 많은 플레이어가 결투를 하느냐 메뉴를 탐색하느냐에 따라 둘을 전환합니다. 컨트롤러가 감지되지 않으면 다른 입력 장치를 분리하고 조작 설정을 다시 확인하세요.

**업데이트 후 키 설정이 초기화된 이유는 무엇인가요?**

**조작을 배우는 가장 빠른 방법은 무엇인가요?**
전투 동작부터 재할당하고, 낮은 위험의 전투에서 테스트하며, 한 번에 하나의 변경만 연습하세요. 첫 대규모 전투 전에 10분을 투자해 사용자 지정한 플레이어는 기본 설정을 그대로 둔 플레이어보다 입력 실수가 적다고 일관되게 보고합니다.
