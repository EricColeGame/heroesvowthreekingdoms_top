설정은 또한 게임이 손에 어떻게 느껴지는지에 영향을 줍니다. 카메라 속도, 가장자리 스크롤 감도, 유닛 선택 동작은 매끄러운 측면 기동과 기병을 창벽으로 돌진시키는 엉성한 명령 사이의 차이를 만듭니다.

## 플랫폼별 설정 메뉴 여는 방법

진입점은 플랫폼마다 다르지만 원리는 일관됩니다: 톱니바퀴 아이콘이나 일시정지 메뉴를 찾으세요. PC 빌드에서는 설정 패널이 보통 메인 메뉴와 전투 중 일시정지 화면에서 접근 가능합니다. 모바일에서는 보통 홈 화면의 프로필 아바타 뒤에 숨어 있습니다. 콘솔에서는 시스템 수준 일시정지 메뉴에 있습니다.

- **PC:** 표준 ESC 키로 일시정지 메뉴를 연 다음 설정 또는 옵션을 선택하세요.
- **모바일:** 홈 화면 상단 모서리의 아바타를 탭한 다음 톱니바퀴 아이콘을 누르세요.
- **콘솔:** 컨트롤러의 일시정지/옵션 버튼을 누른 다음 설정을 선택하세요.
- **웹 또는 에뮬레이터 빌드:** 타이틀 화면 오른쪽 위의 톱니바퀴를 찾으세요.

안으로 들어가면 한 번에 한 카테고리씩 변경하고, 튜토리얼이 아니라 실제 전투에서 테스트하세요. 튜토리얼 조우는 카메라 문제나 프레임 저하를 드러내기에는 너무 작습니다.

| 플랫폼 | 일반적인 접근 경로 | 자동 저장? |
|---|---|---|
| PC | 일시정지 메뉴 → 설정 | 보통 종료 시 예 |
| 모바일 | 아바타 → 톱니바퀴 아이콘 | 예, 계정별 |
| 콘솔 | 일시정지 버튼 → 설정 | 보통 예 |
| 에뮬레이터 | 타이틀 화면 톱니바퀴 | 빌드에 따라 다름 |

## 그래픽 설정: 화려함보다 선명함

가장 큰 실수는 모든 것을 최대로 올리는 것입니다. 블룸, 모션 블러, 과한 파티클 효과는 트레일러에서는 인상적이지만, 연기 자욱한 전장에서 여섯 유닛을 추적하려 할 때는 끔찍합니다.

먼저 안정적인 프레임 레이트를 고정한 다음, 프레임 레이트가 떨어질 때까지 시각 품질을 올리세요. 대부분의 기기에서는 일정하게 낮은 프레임 레이트가 들쭉날쭉한 높은 프레임 레이트보다 낫습니다. 카메라 이동이 부드럽게 유지되고 입력 지연이 예측 가능해지기 때문입니다.

| 옵션 | 하는 일 | 권장 접근법 |
|---|---|---|
| 해상도 / 렌더 스케일 | 이미지 선명도 | 네이티브 또는 네이티브보다 약간 낮게 |
| 프레임 레이트 제한 | FPS 상한 | 디스플레이 주사율과 일치 |
| 그림자 품질 | 지형 및 유닛 그림자 디테일 | 보통 — 높음은 이득 대비 비용이 큼 |
| 효과 / 파티클 | 전투 주문 및 먼지 효과 | 대규모 전투에서는 보통 |
| 모션 블러 | 빠른 카메라 움직임을 번지게 함 | 끄기 |
| 카메라 흔들림 | 충격 시 화면 흔들림 | 낮음 또는 끄기 |
| 블룸 / 글로우 | 밝은 효과의 빛 번짐 | 저사양 기기에서는 끄기 |
| 안티 앨리어싱 | 들쭉날쭉한 가장자리를 부드럽게 함 | 성능이 허락하면 켜기 |
| UI 크기 | HUD 요소 크기 | 작은 화면에서는 키우기 |

두 가지 경험칙: 모션 블러를 먼저 끄고, 해상도를 올리기 전에 UI 크기를 키우세요. 읽을 수 있는 숫자가 예쁜 풀보다 더 중요합니다.

휴대폰으로 플레이한다면 시스템 설정의 배터리 절약 모드나 성능 모드도 확인하세요. 이런 토글은 인게임 그래픽 설정을 완전히 덮어쓰는 경우가 많아, 일부 플레이어가 배터리가 특정 임계값 아래로 떨어지는 순간 품질이 떨어지는 것을 보게 됩니다.

## 게임플레이, 계정 및 편의 기능 설정

비주얼과 입력 외에도 설정 패널에는 보통 게임 플레이 방식을 바꾸는 규칙이 있습니다. 자동 전투 임계값, 전투 속도, 알림 토글이 모두 여기에 있으며 간과하기 쉽습니다.

| 옵션 | 효과 | 누가 바꿔야 하는가 |
|---|---|---|
| 전투 속도 | 전투 애니메이션을 빠르게 함 | 숙련된 플레이어, 파밍 런 |
| 자동 전투 토글 | AI가 전투를 해결하게 함 | 사소한 스테이지를 클리어하는 플레이어 |
| 난이도 | 적 스케일링 및 AI 공격성 | 첫 캠페인 이후 올리기 |
| 피해 숫자 | 떠다니는 전투 텍스트 | 화면이 복잡하면 끄기 |

정말로 원하지 않는 한 푸시 알림을 끄세요. 20분 동안 준비한 공성전을 알림이 방해하는 것보다 전략 게임을 더 빠르게 망가뜨리는 것은 없습니다.

계정 연동은 절대 건너뛰지 말아야 할 유일한 설정입니다. 진행 상황이 로컬 기기에만 묶여 있고 기기를 잃어버리거나 캐시가 지워지면, 그 진행 상황은 일반적으로 복구할 수 없습니다. 옵션이 나타나는 즉시 이메일, 플랫폼 계정 또는 소셜 로그인에 연동하세요.
